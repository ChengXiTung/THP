# THP
Combinatorics-Intensive Texas Hold'em Poker Simulator

Core Features to Prioritize:

Game Simulation Engine

    Card deck management (shuffling, dealing)

    Community card progression (flop, turn, river)

    Turn order and betting rounds (check, raise, fold, call)

    Hand strength evaluation (ranking poker hands)


Bot System

    Configurable difficulty levels (e.g., passive/aggressive strategies)

    Decision-making based on hand strength, pot odds, and bluffing logic

    Support for 1–3 bots with distinct difficulties


Probability & Combinatorics Tools

    Real-time win probability calculator (vs. visible cards)

    Monte Carlo simulations for complex scenarios

    Odds of drawing specific cards (e.g., flush/straight completion)


Economy System

    In-game currency tracking (starting stack, bets, side pots)

    Bankruptcy detection and rewards for winning streaks


Cheat Tools

    "Peek" opponents' cards (debug mode)

    Future: Predict opponent behavior, highlight optimal moves
